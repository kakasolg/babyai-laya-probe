# Baby sprites (puzzle mode trial)

Crawling android baby drawn instead of the car in puzzle mode. Original design (white hair with a cyan streak,
orange hooded vest with a teal badge, grey suit with joint seams).

Made locally on 2026-11-15 with ComfyUI + FLUX.2 klein 4B (Apache-2.0), then background removed, scaled to
80 px (largest frame) with one shared 24-colour palette. AI-generated images; disclose as such where the game is published.
