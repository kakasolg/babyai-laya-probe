# Toy sprites (puzzle mode trial)

ball / key / box drawn as baby toys in puzzle mode: white sprites, tinted at draw time with the object's colour.
Two looks per kind (`_a`, `_b`); each room picks one look per kind from its seed, so a room never mixes looks.

| kind | a | b |
|---|---|---|
| ball | striped rubber ball | bumpy sensory ball |
| key | ring rattle with three keys | one chunky toy key |
| box | soft block with stars | toy chest with a heart |

Made locally on 2026-11-15 with ComfyUI + FLUX.2 klein 4B (Apache-2.0), green-keyed and scaled to about 50 px.
AI-generated images; disclose as such where the game is published.
