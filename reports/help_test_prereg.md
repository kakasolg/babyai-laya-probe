# 도움 시험 사전 기준 — 막힌 판에 사람이 1~3번 도와주면 풀리나 (2026-11-16, 실행 전 작성)

요청: MoKa (11-16 대화) "해결 못한 것들만 모아서 1 turn 사용자 도움이 효과가 있는지, 각각 최대 3 turn까지".
재학습 없음. 결과를 본 뒤 아래 기준을 바꾸지 않는다.

## 모델·판
- 모델: gotolocal-s0, ONNX fp32를 Windows CPU로 (`OnnxChooser`; PyTorch 기록과 944/944 같은 선택, 11-16 확인).
- 판: 개발 seed 10000~10299 중 **도움 없이 실패한 판**. 이 시험이 먼저 300판을 도움 없이 돌려 직접 정한다.
  3.5단계 기록(seed 0 모델 24판 실패)과 같은 목록인지도 적는다. 20000~20299 등 잠긴 범위는 쓰지 않는다.
- 걸음 제한 64 그대로. 도움 걸음도 1걸음으로 센다.

## 막힘과 도움
- **막힘**: 아기가 이 판에서 이미 있었던 (x, y, 방향)으로 다시 온 순간. 방이 변하지 않고 모델은 기억이 없어
  같은 상태에서는 늘 같은 선택을 하므로, 도움 없이는 끝없이 돈다.
  64걸음 동안 같은 상태로 돌아오지 않고 헤매다 끝난 판은 "막힘 없음"으로 따로 센다(도움 기회 없음 → 실패).
- **도움 1번** = 막힌 그 상태에서 모델 대신 행동 하나를 넣는 것. 그 뒤로는 다시 모델이 혼자 간다.
  다시 막히면 남은 도움이 있을 때 또 돕는다.
- 도움 방식 두 가지:
  - **A. 봇 도움**: 그 상태에서 새로 만든 BabyAI 전문가 봇이 고르는 행동(길을 아는 사람이 누르는 버튼).
  - **B. 가장 좋은 도움**: 막힐 때마다 세 행동을 모두 해 보고, 도움 H번 안에 성공하는 길이 하나라도 있는지.
    사람이 고를 수 있는 최선의 위쪽 한계.

## 보고할 숫자
- 실패 판 수 N, 그중 막힘(되돌아옴) 판 수와 헤맴 판 수.
- A, B 각각 H = 1, 2, 3에서 살아난 판 수 / N.
- A로 살아난 판의 걸음 수, 쓴 도움 수.

## 판정 (미리 정함)
- "도움 1번이 효과가 있다" = **A, H=1에서 N의 1/3 이상**이 살아남.
- "도움 3번까지면 대부분 풀린다" = **A, H=3에서 N의 2/3 이상**.
- B가 A보다 많이 살리면 "봇이 아닌 다른 버튼이 더 나았던 판"으로 따로 적는다.
- 3.5단계 막힘 탈출 장치(24판 중 5판 살림)와 비교만 하고 판정에는 쓰지 않는다.

## 하지 않는 것
