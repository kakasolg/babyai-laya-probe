# 11b-3 선언 — 시범 10,000판, 학습 seed s0 (돌리기 전에 커밋)

지시: MoKa가 11-17 이 세션에서 "10,000판도 같이 돌려줘"(11b-2를 돌리는 중). **이 파일을 커밋한 뒤에 덤프 · 학습한다.**
11b 선언의 "하지 않는 것"에 10,000판이 있었다. 이것은 결과를 본 뒤 MoKa가 새로 지시한 추가 실행이며, 11b · 11b-2의 읽기는 고치지 않는다.

## 1. 자료

- 봇 seed 0~9,999, 거르는 규칙은 11b와 같다. `python -m probe.stage11b dump --task {gotolocal|putnext} --upto 10000` → `data/n10000_<task>.jsonl`(git 밖), 요약 `reports/stage11b/dump10k-<task>.json`.
- 먼저 확인: 앞 1,000판이 기존 자료와, **앞 5,000판이 11b의 `data/n5000_<task>.jsonl`과 줄 단위로 같은지.** 다르면 멈추고 적는다.
- 잠근 seed: 0~9,999는 개발용(10000~)과 잠근 범위(20000 · 30000 · 60000 · 70000대) 밖이다. 두 검사(`guarded_seeds`, `stage10.seeds_of`)를 코드가 다시 거친다.
- 남은 판 · 걸음 · 보정 항목 수(같은 비율) · 뺀 seed 목록을 적는다.

## 2. 학습 · 평가

- 11b와 같은 설정 · 같은 평가(걸음 단위 일치, 규칙 없음, R-reset), 학습 seed **s0 하나**. 체크포인트 `~/babyai-laya-ft/n10000-{task}-s0`.
- GPU는 11b-2가 끝난 뒤에 쓴다(겹치지 않게). 덤프는 CPU만 쓰므로 11b-2와 함께 돌린다.
- 예상 학습 시간(5,000판 실측의 2배): GoToLocal 약 46분, PutNextLocal 약 117분.

## 3. 미리 정한 읽기 (s0 하나)

GoToLocal은 5,000판 s0이 이미 291 / 300이라 "+15판" 문턱을 쓸 수 없다. 그래서 두 과제 모두 **5,000판 세 seed(11b + 11b-2)의 규칙 없음 혼자 2배 안의 최소 ~ 최대**와 비교한다.

- 10,000판 s0이 5,000판 세 seed의 **최대보다 높으면** → "5,000판 너머에서도 오르는 것으로 보인다(s0 하나)"
- **최소 ~ 최대 안**이면 → "5,000판 근처에서 평평하다(s0 하나)"
- **최소보다 낮으면** → "5,000판보다 낮다(s0 하나)"
- 5,000판 세 seed 평균과의 차이도 적는다. R-reset 망가뜨린 판 수, 걸음 단위 일치, 막힌 칸 전진 비율, 학습 시간도 적는다.

## 하지 않는 것

10,000판 s1 · s2, 20,000판 이상, 지난 행동 입력, 다른 과제, 최종 seed, 설정 변경, 다시 돌리기.
