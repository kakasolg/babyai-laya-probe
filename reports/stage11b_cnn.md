# 11b 덧붙임 — 같은 시범 수에서의 작은 CNN (2026-11-18, Host: cloud, CPU)

[cloud]가 `reports/stage11b.md`의 곡선 옆에 놓으려고 돌렸다. **Laya가 아니다.** 저장소의 봇 시범과 같은 판(걸음 수가 줄 단위로 같다)으로, 과제마다 따로 학습한 작은 신경망이다.

- 코드 `tools/small_policy/cnn_curve.py`, 원자료 `reports/stage11b/cnn_curve.jsonl`(30줄 + 머리 2줄).
- 모델: 7×7 관측의 물체 · 색 임베딩 → 합성곱 3층(채널 16, 지시문으로 FiLM) → 은닉 64 → 행동. **약 6만 7천 파라미터**(GoToLocal 66,675 / PutNextLocal 66,805). 기억 없음, 지난 행동 입력 없음. 들고 있는 물체는 관측의 자기 칸에 들어 있다.
- 학습: 봇 seed 0부터 앞에서 N판, 선택지 밖 행동이 나온 판은 뺌(GoToLocal 10,000판 중 24판 — `stage11b`와 같은 수). 15에폭, AdamW, 학습 seed 0 · 1 · 2. 걸음 수: GoToLocal 479 / 2,638 / 5,310 / 26,489 / 53,273, PutNextLocal 1,196 / 6,018 / 12,036 / 60,263 / 120,307 — `stage11b.md` 1절과 같다.
- 평가: 개발용 seed 10000~10299, 300판, 환경 기본 걸음 제한(64 / 128). 규칙 없음과 R-reset(key = 관측 + 방향, 같은 정의). "2배 안" = 같은 판 봇 걸음의 2배 안.
- 한 번 학습에 CPU 한 코어로 13초~2분 30초.

## 읽기 (추정 포함)

- **Laya가 앞서는 곳은 시범이 적을 때다.** 옮겨 놓기에서 가장 뚜렷하다: 500판에서 Laya 236 대 CNN 7, 1,000판에서 251 대 15. CNN이 Laya의 500판 수준(236)에 이르는 데는 5,000판이 든다 — 약 10배.
- **시범이 많아지면 격차가 거의 없어진다.** 10,000판에서 GoToLocal 291.7 대 285.3, 옮겨 놓기 276.3 대 265.7. 421M 모델과 6만 7천짜리 모델의 차이가 300판 중 6~11판이다.
- **R-reset은 이 CNN에서도 망가뜨린 판이 0건이다**(30개 학습 전부). Laya 30개 · 학습 없는 모델 일곱 설정에 더해지는 관찰이다. 보장은 아니다.
- 약한 모델에 규칙을 붙이면 성공은 크게 오르지만 2배 안은 덜 오른다(GoToLocal 100판: 성공 58 → 223, 2배 안 49 → 69). `stage12.md`의 학습 없는 모델과 같은 모양이다.
- 이 저장소의 게임 자율주행(`godot/data/policy_l*.json`)과는 구조가 조금 다르다(지시문 임베딩 크기, 출력 수). 그래서 1,000판의 GoToLocal 값(혼자 성공 200)이 `tools/small_policy/levels_results.json`의 값(197~251)과 꼭 같지는 않다.

## 한계

- CNN의 학습 설정(15에폭, 크기)은 한 가지다. 더 크게 하거나 순환 기억을 넣으면 달라질 수 있다 — BabyAI 원 논문의 작은 모델은 기억(LSTM)이 있다. 이것은 "기억 없는 아주 작은 모델"의 한 점이지 가장 좋은 작은 모델이 아니다.
- 평가는 개발용 300판. Laya와 CNN은 입력 표현이 다르다(글 대 격자 숫자).
- LID와의 비교가 아니다.
